# Inventra — Inventory Management System

Inventra is a web-based inventory management system developed using
ASP.NET Core MVC. It helps manage products, suppliers, purchases,
sales, payments, returns, and inventory reports.

## Features

- Role-based access for Admin and Cashier
- Category, supplier, and product management
- Purchase management and stock updates
- Point of Sale (POS)
- Sales history and payment processing
- Invoice PDF generation
- Returns and inventory adjustments
- Admin-only reports and exports
- Cashier account management

## Technologies Used

- C#
- ASP.NET Core MVC
- Entity Framework Core
- MySQL
- MySQL Workbench
- Razor Views
- Bootstrap
- JavaScript
- Git and GitHub

## Prerequisites

- Visual Studio 2026
- .NET 10 SDK
- MySQL Server
- MySQL Workbench (optional)

## Setup

1. Clone this repository.
2. Open the solution in Visual Studio.
3. Create the MySQL database and configure the connection string.
4. Ensure the database schema and required initial data are available.
5. Restore NuGet packages.
6. Build and run the application.

## Security

Configure database credentials locally. Never commit real passwords
or other secrets to source control.
